# Early Ocular Disease Detection

A computer vision project exploring whether deep learning can help identify ocular disease from medical images at an early stage.

**Indus University · July–November 2023**

## Project overview

This project explored a **VGG-16 convolutional neural network** for classifying medical images. According to the project summary, Hiral led model development, worked with a curated dataset of medical images and patient records, and iterated on data management and model optimization.

**Skills showcased:** Python, deep learning, convolutional neural networks, VGG-16, medical imaging, dataset curation and model optimization.

## Reported result

The project summary reports **89% accuracy for early-stage detection**. The dataset, disease classes, test split, sample size and evaluation procedure are not yet documented here, so this is a reported project result rather than a reproducible benchmark.

## Materials and limitations

This repository currently contains a project overview. Source code, trained models, dataset and evaluation artifacts have not been added. Patient records and medical images are not included.

This is a research project and has not been established as a clinical diagnostic tool. Further independent evaluation and clinical validation would be needed before any clinical use.
